# Pijaminha e Companhia — Aprender Brincando

Apresentação web de uma proposta de creche noturna para famílias que precisam de cuidado infantil nesse horário.

## O que você encontra

- Apresenta o problema, a proposta, o público-alvo e a equipe.
- Inclui navegação por carrossel com botões e indicadores.

## Executar localmente

Baixe ou clone o repositório e sirva a pasta raiz com um servidor estático. Com Python 3 instalado, execute `python -m http.server 8000` e acesse [localhost:8000](http://localhost:8000/).
